# Интерактивный блок карточного каталога

Интерактивный блок карточного каталога по макету в Figma с адаптивным дизайном, поиском и фильтрацией.

## Адаптивный дизайн

*   Плавное масштабирование элементов.
*   Отсутствие жёстких медиа-запросов для основных размеров.
*   Корректное отображение на всех разрешениях от 320px до 1920px+.

## Технические требования

**Стек технологий:**
*   **HTML5** (семантическая разметка)
*   **Vanilla JavaScript** (чистый JS без фреймворков)
*   **SCSS** (препроцессор CSS)
*   **БЭМ** (методология именования классов)

**Ограничения:**

❌ **Запрещено** использование библиотек (jQuery, React, Vue и т.д.)  
❌ **Запрещено** использование фреймворков

✅ **Разрешено** только нативный JavaScript  
✅ **Обязательно** использование методологии БЭМ
